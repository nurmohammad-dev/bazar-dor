# বাজার দর / BazarDor

BazarDor is a simple market price web app. It shows today’s prices, price changes, and market-based details for different products.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB

## Key Features

1. View product prices by category
2. View product details and market-based prices
3. Track price increases and decreases
4. Sign up and sign in with email, Google, or GitHub
5. Update your name and sign out from your profile

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.
